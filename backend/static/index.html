Help
安装与排障
扩展需在本机 Chrome 中加载；Web 设置只展示状态，不能修改扩展连接地址。
  1. 打开 chrome://extensions
  2. 开启右上角「开发者模式」
  3. 下载扩展包并解压，或使用仓库中的 extension/ 目录
  4. 点击「加载已解压的扩展程序」，选择 justsearch-bridge（或 extension）文件夹
  5. 在扩展弹窗确认绿色「已连接」，地址与上方期望 WS 一致
已安装仍未连接：检查扩展 popup 地址；桥接与 HTTP 服务共用同一端口，默认 8000（本地）或宿主机映射端口（Docker）。 标签页顶部黄条：扩展通过 debugger 控制标签时的正常提示，任务结束后会消失。 只能连一个扩展：后连接的实例会顶替先前连接。

Google、Bing 等搜索与网页阅读均通过本机 JustSearch Bridge Chrome 扩展驱动真实浏览器。 未连接扩展时无法抓取搜索结果。

状态：未连接
  1. 打开 Chrome，地址栏输入 chrome://extensions
  2. 开启右上角「开发者模式」
  3. 下载扩展包并解压，或直接使用仓库中的 extension/ 目录
  4. 点击「加载已解压的扩展程序」，选择解压后的 justsearch-bridge 文件夹
  5. 点击扩展图标，确认状态为绿色「已连接」
若后端端口变更，可在扩展弹出页修改后自动重连。
